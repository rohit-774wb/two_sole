# HTML Codes

A creative single-page HTML project featuring an interactive animated romantic web experience titled **"Two Souls, One Universe"**.

This project combines:
- a cinematic intro screen
- animated starry background
- draggable glowing soul elements
- a connection animation
- a final love letter reveal

## Project Overview

This repository contains a beautiful front-end web page built with plain HTML, CSS, and JavaScript. It is designed to feel immersive and expressive, with subtle animations and a romantic theme.

## Files

- `index.html` — Main page containing structure, styling, and interactive JavaScript logic.

## Features

- Full-screen animated universe background
- Intro sequence with elegant typography
- Interactive drag-to-connect effect
- Particle and glow animations
- Romantic final message card
- Responsive browser-based experience

## How to Run

Since this is a static HTML project, you can run it directly in your browser:

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.

You can also use a local server if preferred:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
